# 💈 Local Barbershop Website

A responsive website project developed for a local barbershop, focused on digital presence, service presentation and customer experience.

 **[Live Demo](https://projeto-barbearia-local.vercel.app/)**

---

##  About the Project

This project was developed independently as a practical web development project based on a real-world local business scenario.

The goal was to create a modern and responsive website capable of presenting the business, its services, team, gallery and other relevant information in an organized and engaging way.

This project is part of my development journey and portfolio as a developer in training.

---

##  Project Goals

* Create a modern digital presence for a local business
* Present services and packages clearly
* Showcase the business environment and team
* Create an engaging visual experience
* Build a responsive interface for different screen sizes
* Apply modern web development concepts to a real-world scenario

## Running Locally

### Requirements

* Node.js LTS
* npm

### Installation

Clone the repository and install the dependencies:

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Then open the local address provided by Vite, usually:

```text
http://localhost:5173
```

---

## Production Build

To generate the production build:

```bash
npm run build
```

The optimized files will be generated in the `dist/` directory.
