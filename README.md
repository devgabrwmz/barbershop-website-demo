# Demo — Barbearia Prime (Portfólio)

Projeto de demonstração em React + TypeScript + Vite, com dados fictícios
para fins de portfólio.

## Como executar

1. Instale o Node.js LTS.
2. Abra esta pasta no VS Code.
3. No terminal, execute:

```bash
npm install
npm run dev
```

4. Abra o endereço mostrado pelo Vite (normalmente http://localhost:5173).
